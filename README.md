# Частина 1 — відповіді

1. Аудіо-характеристики винесені в `audio_features`, бо це семантично схожі речі - зручніше працювати з ними вкупі і передавати одним шматком, ніж тягати з плоскої структури.

2. Виконавці - масив, бо це однорідні дані. Простіше перевірити, чи є артист серед авторів треку, ніж парсити рядок.

3. `$out` створює колекцію наново (перезаписує), `$merge` додає/зливає з уже існуючими даними.

# Частина 2 — відповіді

1. `$unwind` розгортає масив у окремі документи (наприклад, `artists: ["A","B"]` → два документи). Так зручніше групувати й рахувати по кожному елементу масиву.

2. `$stdDevPop` — стандартне відхилення для всієї сукупності (population), `$stdDevSamp` — для вибірки (sample, ділить на n-1). У нас по жанру беремо всі треки з бази, тому логічніше `$stdDevPop`.
